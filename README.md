# Ecommerce
Live Demo: https://mart-eight-sigma.vercel.app

A full-stack ecommerce web application built using React, Node.js, Express, and MongoDB.

## Features

- User registration and login
- Password hashing using bcrypt
- JWT authentication
- Admin dashboard
- Admin can add products
- Product listing on home page
- Cart functionality
- Protected routes
- Responsive UI

## Tech Stack

### Frontend

- React
- Vite
- React Router
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- bcryptjs
- JSON Web Token
